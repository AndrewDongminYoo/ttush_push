# Changelog

All notable changes to Ttush Push are documented in this file.

## [1.1.1] - 2026-09-18

### Changed

- iOS builds now target iPhone only; iPad support is deferred until the larger layout has been tested.

### Internal

- Added the ad provider boundary with a no-op default, and moved the match-decided report after the frame that paints the result.
- Automated closed Alpha publishing to Google Play behind version, changelog, and upload-certificate preflight checks.
- Pinned GitHub Actions to commit SHAs and upgraded pinact to 4.1.1.
- Raised very_good_analysis to v11.

## [1.1.0] - 2026-09-05

### Added

- Added a setup screen for local two-player matches and four AI difficulty levels.
- Added the strategic Expert opponent.
- Added Korean localization for the full game.

### Changed

- Updated the launcher icon with the palm-pushing rivals artwork.
- Updated the first-match coach so returning testers see the current guidance.

### Fixed

- Corrected Korean result announcements.
